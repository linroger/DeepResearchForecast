## Direct/manual/secondary caller contract (for API owner)

`SimulationManager.prepare_simulation` takes `simulation_id`, `simulation_requirement`, `document_text`, optional entity/profile/progress arguments, and the four context kwargs `actors`, `graph_priors`, `max_rounds`, `research_language`. `actors` MUST be the whole bound dossier object, not its nested actor list, and `document_text` MUST be the exact report text whose hash the actor-intelligence contract carries. No new manager-side data loader was introduced; the caller owns generation selection and policy admission.

The main orchestrator's PREPARE call uses `state.prompt`, `report_md`, `actors`, `state.options.research_language`, and handoff `graph_priors.json`. It passes explicit options.max_rounds, otherwise None for calendar mode or OASIS_DEFAULT_MAX_ROUNDS for hours mode. Its OASIS seed call forwards the same context, with the seed's resolved round budget. For valid `official_data.simulation_research_binding(simulation_id)`, `pipeline_id` and the returned resolved `handoff_dir` identify the consumed generation even when this simulation is secondary and differs from the pipeline's primary simulation_id. Binding proof includes hashes for report, actors, sources, actor dossier, research contract manifest, datasets and optional news context, but not graph priors or pipeline options. Invalid proof cannot justify a mutable fallback or fresh-generation adoption. `bind_simulation_research` is create-only and accepts `expected_generation`; the worker has not changed it.

Do not use the current best-effort `load_research_dossier_for_simulation` as the sole fail-closed resolver: its documented invalid-binding path falls back to pipeline lookup. API/policy owner is handling that boundary. G's omission-comparison case invokes actual downstream generators with the direct route's omitted-kwargs shape, then with the bound kwargs. It observes no actor roles/packs and the wrong inferred language without them; bound invocation observes English, the saved cutoff and through-2029 horizon in actual event prompt input. This is downstream behavioral evidence, not an HTTP route admission test. API/backtest paths remain unedited by this worker.
