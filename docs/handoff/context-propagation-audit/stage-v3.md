## Contract map and findings

Four defects are behaviorally established on base bytes. The scope producer's restated question, horizon and entities were saved but absent from the planning consumer. Generated actor `as_of_date` overrode the admitted historical cutoff. Search rows with any `backtest` mapping bypassed cutoff reevaluation. Fetched ordinary web pages were replayed or republished after byte changes, deletion or symlink substitution without validating their recorded digest (datasets already had stronger checks).

The first bounded repairs pass normalized scope to the actual planning task, keep `plan.as_of` authoritative in actors.json, reevaluate all historical search rows using the current policy and validate stored web bytes before tool replay/QA/finalization. Changed/missing web evidence cannot silently refetch under its original source ID.

Two additional behavioral failures were established after those repairs: QA section corrections left the executive summary using retired lead values, which reached structured extraction; and context rows 5–12 were actually in KIQ task text but were absent from that agent's shown-source set, causing valid citations to be discarded. Repairs bind summary-cache input/body hashes, refresh summaries from revised QA leads (falling back to corrected leads if necessary), and track the exact context citation aliases as task rendering admits them. This does not widen access to unseen ledger rows or increase the four-context-seed cap.

The final resume-path sweep reproduced three further defects: a matching state could reuse a plan with a foreign question/language/cutoff; a foreign KIQ record with the same short ID was accepted and could enter a newly built writer digest; and `qa_report.md` could change without matching `qa.report_sha256`, then be republished and re-extracted. Repairs validate saved-plan admission fields and derived brief, require KIQ question/kind/round agreement, and reject QA-report hash mismatch. These are local consistency guards, not authentication against deliberate simultaneous rewriting of all state and proof.

## Adjacent boundary notes and residual limits

The incoming boundary is `_Engine(question, out_dir, args, meta, ... env)`, not an API request. The outgoing boundary is the exact final report, cited-only `sources.json`, actors/situation/forecast inputs, quantitative/events/contested files, published data manifests and meta. The coordinator must reconcile its attempt identity, parent news question digest, actor policy/sealing, required official evidence, final artifact seal and downstream extraction against these outputs. No orchestrator/API/legacy-engine/actor-access code was edited by this worker.

Source-only limits, rather than reproduced new bugs: (1) `_catalog_seeds` explicitly documents coarse routing of compound question matches to the first data KIQ; this can over-broaden retrieved context even though every series is labelled and relevance instructions remain. (2) Scout results are hard bounded to 6000 chars; KIQ/digest/context/lead selectors intentionally omit information. Digest omission count is persisted/logged, not proof that every omitted fact was unimportant. (3) `synth.json` and per-section files have structural resume checks, not a new complete authenticated artifact graph; changing both state and proofs is not prevented. (4) A method-library or non-identity option change during resume can retain an earlier completed plan/extraction; the parent owns saved option policy. (5) The summary's 700-character leads and gap review's bounded open/discovered lists are partial views. No demonstrated semantic failure is claimed for these limits, and no blanket correctness verdict follows from helper tests.

Normalizers retain many actor attributes, but their existence in `actors.json` is not proof of downstream actor-specific use. The prepare/simulation owners must trace those fields into their actual prompts. Historical controls enforce supplied metadata/capture/vintage admission, not the absence of future knowledge inside an LLM's pretrained parameters. External models, searches, publisher pages, data sources and network-bound finalize services are scripted here; real engine, gateway, ledger, prompt construction, persistence, QA, report parsing and relevant consumers remain real.
