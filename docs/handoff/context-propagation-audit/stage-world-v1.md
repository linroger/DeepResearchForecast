## Reproduced defects, repairs and consequences

**WV-CTX-1 — private evidence relabeled as an assumption (local repair verified).** `_Sources.basis` rejected foreign private claim references, but the text safety check only retained globally denied/analyst text. A modeler could copy actor-known text verbatim into another actor profile/name, public rule, shared menu description/input enum, public scheduled rule effect or public assumption. The compiler accepted it and the real outsider SDK request or frozen public report context consumed it. All seven channels have meaningful behavioral red evidence on original compiler bytes. The compiler now preserves the permitted owner of nonpublic claim text and checks the receiving audience, even with an assumption basis. The existing normalization and short-exact versus specific-substring policy is reused. Authorized own-actor, public-source and analyst-only controls pass. This is literal/normalized copied-text protection; it does not prove semantic detection of paraphrases or numerical inference.

**WV-CTX-2 — delayed context exposed by results before delivery (local repair verified).** A queued message was absent from the recipient's prompt but present verbatim in actor/public result JSON before its deliverAt boundary. The narrow result filter now applies delivery time to interactions and related event receipts, using each selected historical snapshot's simulated time. Senders and analyst retain queued context; recipient/public gain access at delivery. Controls cover both message and agreement terms, both audiences and historical views. Core reducer state, probability policies and result schema are unchanged. Previously frozen exports whose projections contain premature context fail the existing current-projection binding check; they are not silently repaired or rewritten. Any migration/re-export of saved data needs a separately reviewed operation; none was performed here.

**WV-CTX-3 — generation identities changed causal outcomes (local repair verified).** The former WV-CTX-S1 concern was compared directly with accepted local commit `fe2276a2c1eb248d3ed5dc892ee7cd3190461121`, which a read-only ancestry check confirms is not an ancestor of this checkout. Its verification record documents 925 historical passing cases, including 45 causal cases; those counts were not reused as current proof. The current-source red reproduces wrong scarce-resource recipients, tied bundle ordering, simultaneous delayed-policy state, incorrect next-observation permit state, inbox selection and presented-queue accounting. The red is 35 failed/33 passed: missing-new-map setup failures are retained but are not classified as behavioral downstream repros.

Only the four accepted production-file diffs were ported with matching hunks, without cherry-pick, checkout, reset or whole-file replacement. `contracts.py`, `kernel.py` and `observations.py` are byte-identical to the accepted commit. `compiler.py` combines its two causal hunks with the current audience-aware privacy repair. `results.py` retains exactly the prior selected-time privacy filter hash. New compilation pins causal-v1; already-sealed unpinned worlds keep the old policy. Tied actions use submitted position after explicit priority; simultaneous boundary work applies declared schedules, causal commitments, then expiries. Offer/message windows consume the same durable origin map as staging, queue service and exact event-budget probes. Normalized positions are reducer-derived, and origin coverage/creation slot/source identity is validated. The map and internal positions are absent from actual actor/public projections.

The only production edits are now `compiler.py`, `contracts.py`, `kernel.py`, `observations.py` and `results.py`. The owned test file contains all 68 focused cases; no unowned test files, peer paths or Git state were changed.
