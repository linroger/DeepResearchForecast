# Supporting state, progress, and utility modules

Source: main commit `c20ec60909fa1aa15154bb6fdb3fdb71c421e10e`. The coordinator read all sixteen files below in full. The orchestrator is documented separately by two specialist readers.

| Python module | Responsibility and workflow relationship |
|---|---|
| `backend/app/models/project.py` | `Project` and `ProjectStatus` describe uploaded/extracted source material, the prediction requirement, ontology, and graph pointers. `ProjectManager` stores `uploads/projects/<project_id>/project.json`, `extracted_text.txt`, and `files/`. Metadata uses atomic JSON writes; the extracted text has its own file. The pipeline creates this project after research and stores its ID in pipeline state. |
| `backend/app/models/task.py` | `TaskManager` is a process-local, lock-protected singleton. It exposes task progress, results, and failures for polling. Tasks have pending/processing/completed/failed states. Its dictionary is not the durable pipeline checkpoint; restarting the process loses this task registry. |
| `backend/app/models/__init__.py` | Re-exports project and task types/managers. |
| `backend/app/services/__init__.py` | Re-exports the ontology, graph, entity, profile, simulation, graph-memory, and IPC services. Importing this package brings a broad service dependency surface into the process. |
| `backend/app/services/requirement_spec.py` | Pure parsing of the user's forecast brief into output language, binary-forecast minimum, page budget, and selected themes. Explicit language directives precede script detection. Missing instructions fall back to English. Downstream report logic can consume a structured output contract instead of inferring everything again. |
| `backend/app/services/research_progress.py` | Estimates numeric research progress from bridge-authored lifecycle events. Legacy and v3 vocabularies are separate. Tool/result text cannot advance phase boundaries; activity moves only within the current band. Parallel lanes use a monotonic mean with room reserved for merge. The live tail has explicit file/line/track limits; the full-history path preserves repeated events and complete lines, and rejects an oversized exact snapshot rather than returning a mislabeled tail. |
| `backend/app/services/text_processor.py` | Adapts file extraction, normalization, configured chunk size/overlap, and text statistics. The graph producer uses chunks as episode inputs. |
| `backend/app/utils/__init__.py` | Re-exports `FileParser` and `LLMClient`. |
| `backend/app/utils/atomic.py` | Writes to a sibling temporary file, flushes, optionally fsyncs, and installs with `os.replace`. `fsync=False` retains atomic replacement but skips durability flushing for frequently replaced progress files. It removes the temporary file on `BaseException`. |
| `backend/app/utils/chart_html.py` | Inlines a sibling `plotly.min.js` into chart HTML served in a sandbox that allows inline scripts. A small cache is keyed by real path, modification time, and size. A bundle containing a raw closing script token is refused. |
| `backend/app/utils/dates.py` | Lenient UTC-aware date parsing for structured research, temporal graph edges, and event scheduling. It accepts datetime/date objects, numeric/CJK dates, year-month, and year alone. An invalid day can fall back to the month's first day; unparseable input returns `None`. |
| `backend/app/utils/file_parser.py` | Supports PDF, Markdown, and text extraction. PDF reads use PyMuPDF; text decoding tries UTF-8, charset-normalizer, chardet, then replacement decoding. Multiple-file extraction records an extraction failure in the combined text. Chunking seeks sentence/paragraph boundaries and retains overlap. |
| `backend/app/utils/logger.py` | Provides console and daily rotating file logging. Import initializes the default logger and log directory. A console handler tolerates closed streams during shutdown. File log level comes from `LOG_LEVEL`, with INFO as the default. |
| `backend/app/utils/security.py` | Shared recursive secret masking, inline-token masking, environment-value validation/quoting, and operator URL validation. The URL helper resolves addresses and blocks link-local, multicast, reserved, and unspecified destinations; the private-address setting additionally blocks loopback/private destinations. Local LLM endpoints are allowed by the default policy. |
| `backend/app/utils/zep_paging.py` | Reads graph nodes and edges with bounded pagination and transient retries. UUID de-duplication and a no-new-UUID stop protect callers from ineffective cursors. Node cap resolves `GRAPH_MAX_NODES`; edge cap defaults to 10,000. Results feed entity selection, retrieval, graph metrics, and visualization. |
| `backend/app/utils/zep_rate_limit.py` | Recognizes rate-limit exception strings and computes retry delay from Retry-After, reset time, or fallback, with a buffer and optional ceiling. This is compatibility pacing used by graph callers. |

The distinction between durable pipeline state and process-local task state is essential when following a restarted run. The model/manager files, atomic helpers, and progress estimator explain why UI progress, durable stage completion, and actual artifact validity are related but separate observations.

No application modules were imported during this study, and no parser, logger, graph client, or manager was executed. The coverage receipt is `coordinator-coverage.json`.
