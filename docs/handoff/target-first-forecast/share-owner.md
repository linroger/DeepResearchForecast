## Final interfaces and evidence
`worldstate.build_world_state_seed(existing_seed, share_prior="uniform", share_source="auto", forecast_case=None)` is for fresh seeds only. It preserves timing fields, replaces base_rates with uniform shares, and records prior/source/selection reason. Canonical case target identities and exact scenario names/IDs admit reducer-only predicate maps; missing, invalid or private targets select power_votes in auto mode. Explicit predicates stay explicit and freeze when unavailable.

`WorldState(scenarios, base_rates, inertia, *, share_prior=None, share_source=None, scenario_predicates=None, target_node_id=None, share_source_reason=None)` preserves original output and arithmetic when policy is absent. Explicit votes uses the original converter/pressure/step branch. `step_from_source(decisions, *, weight_by_agent=None, resolutions=None, target_values=None, target_reason=None, **step_options)` accepts exact agent-ID trusted power maps and resolution strings success/partial/blocked/failed/pending; missing inputs do not gain implicit power. Current-round public node maps or lists of per-path maps feed predicates. Each runtime path supplies its own map; aggregation is performed once. Freezes preserve failed/missing/infeasible accounting and do not decay convergence EWMA.

`world_model_seed.build_world_model_seed(..., forecast_case=None, share_source=None)` attaches canonical target_projection only for a valid public target with a typed mechanism identity. Public variables appear target first; private nodes stay inside the kernel-only projection. No expression evaluation occurs here. Generic legacy power aliases are retained for unconfigured/votes calls; new explicit policies use only outcome_power. The coordinator added the fresh config generator argument; kernel propagation and write rejection remain owned by the legacy team.

`simulation_record.share_policy_note(shares, lang="en")` provides shared English/Mandarin prior/source/freeze wording. Records persist share_prior, share_source, share_source_reason and share_update_reason. The report owner integrated the same helper into the bridge.
