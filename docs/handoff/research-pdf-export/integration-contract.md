Strict JSON parsing; bounded calls, per-call timeout, repairs and transport retries. Persist reusable completed phase evidence and ambiguous call state for explicit retry; do not replay unknown dispatch outcomes silently.

## API/UI contract
POST `/api/research/<pipeline_id>/dossier/pdf-export` and POST `/api/report/<report_id>/pdf-export`, JSON `{lang: null|'en'|'zh', retry?: boolean}`. Returns HTTP202 for pending,200 for completed matching cache, normal error status otherwise, envelope `{success:true,data:job}`.

GET same base + `/<job_id>` returns `{success:true,data:job}`; GET same base + `/<job_id>/download` returns application/pdf attachment only after job completion and renewed source admission. Optional POST `/<job_id>/cancel` requests stopping the job.

Job public shape: `{job_id,kind,resource_id,requested_lang,language,source_digest,state,phase,progress:{...},error:null|{code,message,retryable},download_url:null|string}`. States queued,running,completed,failed,interrupted,cancelled,stale. The POST is the only operation starting/resuming agent work. Reads and downloads do not call a model. Duplicate POST returns same matching active job. Failure preserves previous exports. Explicit retry is bounded and reuses only matching completed evidence. URLs honor existing `apiUrl` deployment prefix.

Frontend: original PDF controls use this flow and download automatically when completed; Markdown export stays unchanged. Both controls expose busy phase and safe error/retry. Bind every async response to surface resource+language+local request token. Unmount/source/language switch invalidates observers/downloads; distinguish UI cancellation from backend cancellation. Reject wrong resource/language/job and non-PDF response. Use server filename safely. No silent old-renderer fallback.
