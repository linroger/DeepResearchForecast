# Approved v4 private-field contract

Phase17 is closed. Independent design review approved this explicit versioned acceptance expansion with the precision rules below. It does not establish that any unknown phase17 field is commentary or correct.

## Strict controls and canonical form

New explicit MODE_V4='actor-consistency-v4'; old modes remain unchanged. The model request may keep the exact v3 preferred wire instruction to isolate parsing/audit representation. Only fresh v4 actor HTTP output passes through normalize_v4_assessment_output(raw). Outer response remains exactly decision/assessment; raw assessment remains exactly checks, an array of exactly four objects. Each raw check MUST contain one kind from KINDS and one verdict from consistent|inconsistent|unknown, with all four kinds unique. Missing, duplicate, malformed or conflicting control fields reject; no control value is inferred.

The canonical v4 assessment remains exactly checks. Each canonical check is exactly {kind,verdict,fields}. fields is a nonempty dictionary containing EVERY original parsed member except kind and verdict, under its original key. The normalizer does not unwrap, concatenate, drop, truncate or reinterpret any value. Even an original member named fields stays as fields.fields, so reconstructing {kind,verdict,**fields} exactly recovers the original parsed check under existing NFC/strict-JSON semantics. No explanation key or text is manufactured. Shared validate_assessment for v4 accepts canonical form ONLY; store/reopen never normalize saved data again. Aggregate status derives only from the same four explicit verdicts, with any unknown/inconsistent withheld. Preserve valid-unresolved private evidence for v4 as for v3.

## Bounded uninterpreted data

Proposal limits per fields map: 1..8 top-level members; total canonical UTF-8 bytes <=2048; nesting depth <=4 with fields at depth0; total nodes <=128; each nested list/object <=16 members; all keys nonempty strings <=128 characters. Retain only existing strict-JSON value types (null,boolean,integer,string,array,object); no floats or nonfinite values. Reject excessive content rather than trimming. Require at least one nonempty string value anywhere in the bounded tree, preserving the existing minimum requirement for descriptive material without claiming it is meaningful or true.

At the first level, reserve action/server/aggregate names: kind,verdict,status,decision,assessment,checks,intents,stateUpdates,actorId,observationId,round,phase,decisionId,intentId. These cannot be fields keys, preventing alternate action/identity/aggregate slots; kind/verdict are already removed only from their unique required positions. Other keys are opaque model-generated data, never instructions, evidence bindings, capabilities, actions or override channels. Nested data cannot become authority. The full fields map must be retained in private receipts and inspected by independent qualitative review, including contradictory, irrelevant or misleading material. Format admission is not semantic approval.
