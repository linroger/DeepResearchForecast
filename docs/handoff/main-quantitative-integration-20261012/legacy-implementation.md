## Contracts and limits

`_render_data_charts(out_dir, *, plog=None, question="", lang="en")` returns only existing, contained flat `data_*` PNG rows, drops missing HTML links and binds captions to the current stored manifest citations. V3 has a production `bridge_call` to this helper; the legacy lifecycle invokes it before sealing. `_finalize_data_series(out_dir, *, plog=None)` performs no refresh and publishes positional source identities before the dataset manifest. Hash-bound lane snapshots allow global synthesis to finalize without reopening the lane's files or contacting providers.

Tool-time references are deterministic content-bound integers above the ordinary citation range. Exact URL/snapshot/page provenance is preserved through restart, lane export/import, global remap and final numbered References normalization. Same-URL/different-body actor receipts are rejected or the earlier admitted dataset is retained; no Track-B scope is transplanted to a dataset page. Existing actor receipt predicates are unchanged. Search metadata produces no fetched source, and no observed VERIFIED fact is manufactured from a projection.

Per-artifact-directory defaults are fifty charged requests overall and four per injected thread, using the existing `RESEARCH_LINEAR_MAX_DATA_CALLS_TOTAL` and `RESEARCH_LINEAR_DATA_CALLS_PER_KIQ` overrides. Successful repeats and recorded failures do not trigger another provider call. A captured series is immutable for that run: asking for a different date window returns an explicit unavailable message. Budget/candidate corruption fails closed and never silently refreshes. Cross-outer-lane aggregate budget enforcement remains the coordinator's research-stage boundary; these legacy counters coordinate processes sharing one artifact directory.

No live provider or paid-model call, saved-run read/resume, service restart, installation, deployed-config overwrite, Git commit or unrelated-file cleanup was performed. Provider transport correctness, live-model behavior, deployment reconciliation, and the overall quantitative integration acceptance belong to their respective owners. No renderer code was edited. Future verification must use a new evidence directory and rehash sources after any owner changes the shared adapter or bridge.
