## Shared public Python API

All modules support package and bare bridge imports and are stdlib-only at import. Provider URLs are fixed allowlisted HTTPS endpoints. No import-time I/O, dotenv reads, model calls or network. The coordinator owns contract changes; workers must report proposed API deviations before changing their peers' assumptions.

`deerflow_bridge/news_signals.py` owns both source clients and the single run-local store:

- `CONTEXT_FILENAME = "news_market_context.json"`; `ContextIntegrityError(ValueError)`.
- `get_context_client(artifact_dir=None, *, question=None, language=None, as_of=None)` returns a process-cached `ContextClient` keyed by trusted artifact directory. `None` identity arguments reuse an existing client's identity; explicit changed question/language/cutoff must not silently reuse its generation. An explicit artifact dir overrides `DEERFLOW_RUN_ARTIFACT_DIR`.
- `ContextClient.search_news(query, *, deadline=None) -> dict`; `search_social(query, *, deadline=None) -> dict`; `market_compare(query, *, deadline=None) -> dict`. `deadline` is an absolute monotonic float or an object exposing `remaining()`; a caller can only shorten the configured cap. Market comparison lazily delegates to `market_intelligence.compare_markets(self, query, deadline=deadline)`.
- `ContextClient.record_result(provider, query, result) -> dict` records a normalized provider result in the same store, preserving request/item identity and a status record even for empty or failed attempts. The market adapter uses this API. Repeated query identity replays a stored response; it never silently adds a request after sealing.
- `ContextClient.snapshot() -> dict`; `ContextClient.seal(*, source_refs=None) -> dict`. Source refs map canonical URLs to `S<number>` strings; callers may omit them. Seal is idempotent, persists the digest and prohibits further acquisition. Research gathers/fetches/registers sources before seal; late model queries may only replay existing requests.
- `load_context(artifact_dir, *, require_sealed=True) -> dict`: missing file returns `{}` for compatible old/off runs; malformed, oversized, symlinked or tampered present files raise `ContextIntegrityError`. No provider access. `merge_contexts(input_dirs, output_dir) -> dict` merges valid sealed generations deterministically by provider-qualified item identity and capture identity; source references are treated as lane-local until final citation remapping. A corrupt supplied generation is never silently skipped.
- `render_context(context, *, lang="en", max_items=12) -> str`: safe bounded Markdown with links, provider/kind/time/status and explicit context-only limitations. Empty/missing context renders `""`; unavailable attempted providers produce an honest bounded status. No synthetic sentiment probability, trade instruction or automatic anchor.

`deerflow_bridge/news_tools.py` owns legacy reflected tool wrappers `news_search_impl(query)`, `social_search_impl(query)`, `market_compare_impl(query)` returning JSON strings and corresponding `*_tool` LangChain objects when available. Use the process-cached trusted client, never model-supplied paths, provider URLs, keys or arbitrary filesystem access.

## Stored envelope and normalized responses

Envelope schema version 1 contains `generation_id`, `question_sha256`, `language`, `as_of`, `created_at`, `sealed`, `providers`, `queries`, `items`, and `sha256`. Optional bounded metadata must not change these meanings. `sha256` hashes canonical UTF-8 JSON of the envelope without its own `sha256` field (sorted keys, compact separators, ensure_ascii=False, allow_nan=False). During gathering it can be rewritten atomically under a safe thread/process lock; after seal it is immutable. Storage is bounded regular files, no symlink traversal, and atomic replace. Maximum envelope 2 MB, 120 total items, bounded query count. A generation identity never depends on a credential.

Provider result: `{provider, query, status: {state, attempted, reason?, ...bounded counts}, items: [...], retrieved_at, ...bounded request metadata}`. Canonical status states: `ok`, `verified_empty`, `disabled`, `unavailable`, `forbidden`, `rate_limited`, `timeout`, `budget_exhausted`, `partial`, `unsupported`. Missing keys are unavailable, not verified empty. Errors expose stable codes/types, not raw response bodies, URLs containing auth or exception strings.

Item base fields: `id` (provider-qualified native identity), `provider`, `kind`, `title`, `url`, `published_at` (or null), `retrieved_at`, `language`, `query`, `snippet` (bounded), `source_ref` (optional), `eligibility: {context_only: true, anchor: false, resolution: false}`. Kinds: `news_snippet`, `social_post`, `market_quote`, `community_forecast`. Provider-specific fields retain publisher/native ID, evidence/content hash, quote basis/units, bid/ask/last, rules and end date where known; unknown stays null. Market quotes may expose an indicative `probability` only for a known binary outcome price, labeled with basis and never anchor-eligible. Metaculus forecaster count is not dollar volume.

Request identity includes provider, normalized query, language, cutoff/publication window and method/schema version. NewsAPI at most 2 distinct network requests per canonical research generation, 20 items/request, one page, 10-second cumulative acquisition allowance (excluding model/idle gaps) and <=5-second HTTP timeout. Optional Reddit defaults off and is separately bounded. In multi-track research only the designated baseline lane gets the NewsAPI allowance; other lanes have zero. Both tool-attempt and physical-network admission use existing `research_budget` functions; caches/replays consume no network allowance. No retries on 401/403/429. Run/agent limits and cancellation must also constrain gateway dispatch.

## Coordinator amendments from integration review — 2026-10-18

These narrow amendments implement the already approved invariants. They do not relax source identity, proof validation, request caps or publication gates.

1. **Canonical parent question across research angles.** The parent runner explicitly supplies internal `NEWS_CONTEXT_QUESTION_SHA256`, computed from the full whitespace-normalized original pipeline prompt. The runner overrides ambient values and passes the same validated lowercase 64-hex digest to every lane and final synthesis. The provider/cache and research identity checks honor this parent digest; an absent value uses the full direct-run question hash. An invalid present value fails validation. The variable is internal lineage metadata, not a Config setting or credential, and is not documented as a user override. Existing strict merge checks stay intact. Tests must show valid angle-prefixed lanes merge under their shared parent, while a foreign parent or language/cutoff still fails. No truncation of question identity to the 500-character provider-query limit is allowed.

2. **Atomic external market capture.** The provider-owned API adds `ContextClient.capture_market(provider, query, acquire, *, deadline=None) -> dict`. `acquire(reserve_network)` is a trusted adapter callback returning the normalized provider result. The store holds its existing bounded thread/process lock; validates bound identity/sealed state; checks replay and query admission before callback execution; persists interrupted-capture proof before acquisition; and supplies `reserve_network()` that durably charges each physical request against the shared market allowance before I/O, including the existing research network budget. The callback invokes that reservation once before every HTTP request. The store finalizes the pending query atomically without making public `record_result` overwrite arbitrary captured results. Replays, full query tables and uncaptured sealed queries make no new HTTP calls. Process death retains the reservation/interrupted result; identical or distinct concurrent processes cannot each spend a fresh allowance. `market_intelligence` reuses this API and does not create a separate persistent lock/store or double-count budget admission. Direct unit-only fake clients need explicit test adapters; the production path uses the real ContextClient.

3. **Sealed-state monotonicity.** A client that observes or creates sealed proof pins its digest as well as generation identity. A valid but different same-ID envelope, an earlier unsealed predecessor, or deletion cannot reopen its acquisition. Fresh-process loading of the same valid sealed bytes remains compatible. Parent declarations distinguish deleted required context from legacy never-present context, including the real resume and PREPARE exception branches.

4. **Actual comparison presentation.** Tool output, research/report prompt context, deterministic Markdown and UI retain bounded stored literal outcome, bid/ask/last, quote/probability basis, quote and volume units, rules/horizon/threshold, and explicit unknown quote time. Original research-ledger references cannot appear as unqualified final-report S citations. Direct original URLs remain authoritative. Exact validated deterministic metadata blocks must survive stabilization before the final read-only audit; no audit/grounding bypass or post-seal repair is allowed.

5. **Explicit new-run retirement, distinct from resume.** Add provider-owned `archive_context(artifact_dir, archive_dir, *, expected_generation_id, expected_sha256) -> dict`. This is called only by the trusted engine after it establishes a genuinely changed run identity and validates the old context against the old state/binding. Under the existing root lock, verify the exact expected capture and safely move its unchanged file into the engine's archived work directory, contained beneath the same output root; no symlink or destination overwrite is allowed. Preserve archived proof and invalidate only the old cached client registration after successful archival. Existing references to the retired client continue to fail on replacement/missing proof. A fresh client may bind the new explicitly requested generation. Corrupt/missing required proof or an unchanged resumed identity must never use this operation to recover silently. Do not expose the operation as an agent tool, access cache internals from research code, or weaken normal changed-identity rejection. The context-ON regression must cover archived bytes/state, a genuinely new generation and actual acquisition, plus rejection by the old client. Historical web-only fixtures explicitly disable the new feature; they do not replace this ON acceptance.

6. **Acquisition time, independent of model planning.** New envelopes carry finite, nonnegative `acquisition_seconds`. Under the existing cross-process root lock, reserve the entire request timeout for news or residual callback allowance for markets before I/O and settle it to actual monotonic acquisition elapsed only after successful control return. An interruption retains the full reservation. Restart never resets accrued time; legacy unsealed captures with `network_started_at` or positive root/query physical-request counts but no time counter conservatively have no remaining acquisition allowance. Existing sealed replay is unchanged. Do not subtract idle/model time between source calls. Absolute caller deadlines and lock bounds still apply. A successful `reserve_network()` additionally returns an absolute monotonic `deadline` that the native adapter MUST use to narrow its connection/body timeout to the store residual; denied reservation shape stays unchanged. The counter is part of the same digest-bound envelope, with no second time store.
