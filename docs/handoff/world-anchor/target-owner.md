## Exact report-evidence provenance interface

```python
anchored_case_provenance(case, *, pack, requirements, index, policy) -> dict
```

This new pure API reconstructs the native case using the same `_compile` path as apply/validate, checks exact equality, and returns detached privileged metadata. Existing apply/validate/run_paths signatures and compiled case output are unchanged. It performs no provider or filesystem calls and never grants public permission based on node visibility.

The schema is `world-anchor-case-provenance/v1` with `case_hash`, `pack_hash`, and these exact maps:

- `claims[claimId]` contains `node_id`, `origin` (`initial_state` or `actor_authority`), `requirement_id`, `binding_id`, `observation_id`, `ref_id`, `selector`, and the emitted native `source_ids`. Authority selectors are the independently approved authority field's exact selector, not an inferred ID or every observation reference.
- `sources[sourceId]` is a list of `SourceLink` rows for the actual selected evidence that produced that native source row.
- `node_sources[nodeId][sourceId]` is the list for that exact node/source incidence, including authority claims attached to a public control node.
- `parameter_sources[mechanismId][slot][sourceId]` is the list for that exact parameter/source incidence. Slots use the existing `coefficient:<inputNodeId>` names and native scalar names.
- `mechanism_sources[mechanismId][sourceId]` records retained mechanism-level source references. These inherited references are not newly authenticated by parameter binding and have empty link lists.

Each `SourceLink` has `requirement_id`, `binding_id`, `observation_id`, `source_key`, and selected `ref_ids`. Every native source ID and node/parameter source occurrence is represented. An empty list means no admitted anchor mapping for that inherited occurrence; it is not permission to publish. A selected source may have multiple uses, and public permission for one use does not authorize another. The consumer must apply exact observation/binding audience, value kind, and complete reference/support/source closure. Non-evidence prose and other case fields receive no permission from this map. Use the authenticated context's pack and case pins; do not cache solely by a case hash when the pack differs.

All trace IDs, selectors, hashes, and counts are privileged and may vary with private-only input changes. They must not be copied into public `worldAnchor` diagnostics. The report owner owns the ephemeral permission decision and any stable public rendering/citation normalization; this API supplies exact joins without modifying the case.

All source bytes and hashes are fixed before admission.
